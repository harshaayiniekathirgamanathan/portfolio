## 📌 Overview

This repository contains the source code for the personal portfolio website of **Harshaayinie Kathirgamanathan (Harshaayinie.K)**, a 2nd Year **BSc (Hons) in Information Technology** undergraduate at the **University of Kelaniya** (Faculty of Science, Department of Industrial Management).

The portfolio is designed around her primary career goal of becoming an **Aspiring Data Engineer**, showcasing practical projects in ETL data pipelines, SQL databases, data analytics, and software development.

---

## 🛠️ Technologies Used

- **Frontend & Framework**: React, Vite, Tailwind CSS
- **Icons & Styling**: Lucide React Icons, Glassmorphism UI, Custom CSS Data Grid Patterns
- **Deployment**: Vercel (Automated CI/CD from GitHub `main` branch)
- **Data & Tools Stack**: Python, Pandas, NumPy, SQL, PostgreSQL, Power BI
